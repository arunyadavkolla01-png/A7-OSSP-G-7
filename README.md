# Multi-User Linux Shell

A simplified Linux shell that provides username/password
authentication and an individual shell session for each user.

## Week 1 Features

- Linux development environment
- Project structure
- User authentication
- User-specific shell session
- Interactive REPL
- Makefile
- Git/GitHub

## Week 2 Features

- Dynamic command input
- malloc()
- realloc()
- free()
- Arbitrary-length commands
- Modular input handling
